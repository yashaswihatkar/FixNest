# FixNest
AI-powered home appliance support platform with chatbot assistance and technician booking.

## Features

- AI Chatbot Support
- Home Appliance Troubleshooting
- Technician Booking System
- Admin Dashboard
- Real-Time Firebase Database
- Complaint & Service Request Management
- Analytics Dashboard

## Technologies Used

- HTML
- CSS
- JavaScript
- Firebase Firestore
- Chatbase AI

## Supported Appliances

- Electric Kettle
- Rice Cooker
- Vacuum Cleaner
- Electric Iron
- Table Fan
- Mixer
- Toaster
- Hand Blender
